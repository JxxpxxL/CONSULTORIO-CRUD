# CONSULTORIO-CRUD

App Android para gestión de citas médicas. Permite crear, listar, editar y eliminar citas de pacientes usando CRUD completo.

### **🚀 Características**

- Registro de datos personales del paciente
- Selección de fecha y hora para la cita
- Resumen de la cita antes de confirmar
- Listado de todas las citas agendadas
- Edición y eliminación de citas existentes
- Base de datos local con SQLite

### **🛠️ Tecnologías Usadas**

- **Lenguaje:** Kotlin
- **UI:** Jetpack Compose
- **Arquitectura:** MVVM
- **Base de datos:** SQLite con `DatabaseHelper`
- **IDE:** Android Studio
